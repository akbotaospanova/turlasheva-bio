# Жасушаның құпия әлемі

9-сынып оқушыларына арналған биологиядан элективті курс (34 сағат).
Авторы: **Турлашева Алина Маратовна**, №169 мектеп-лицей, Алматы.

## Құрамы
- `index.html` — басты бет
- `style.css` — дизайн
- `engine.js` — 3D қозғалтқыш
- `scenes.js` — 34 сабақтың 3D анимациялары
- `data.js` — сабақтардың мазмұны, тесттер, ойындар
- `app.js` — сайттың жұмыс логикасы
- `img/` — сурет, сертификаттар мен дипломдар

## GitHub Pages арқылы ашу
1. GitHub-та жаңа репозиторий жасаңыз (мысалы, `jasusha`).
2. Осы папкадағы барлық файлды (img папкасымен бірге) жүктеңіз.
3. **Settings → Pages → Branch: main / (root) → Save**.
4. 1–2 минуттан соң сайт `https://ЛОГИН.github.io/jasusha/` мекенжайында ашылады.
